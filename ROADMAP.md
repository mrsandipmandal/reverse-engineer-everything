# Roadmap

Work is split into small, reviewable phases. Each phase starts with acceptance criteria and tests, lands through CI-gated pull requests, and does not implement unrelated phases.

| Phase | Scope | Status |
|---|---|---|
| 0a | Go module, `ree version`, repository baseline, CI, open-source files | Complete |
| 0b | MCP server, `ree doctor`, security and release workflows | In progress |
| 0c | First release, repository hardening | Planned |
| 1 | Evidence core, canonical JSON, schema validation | Planned |
| 2 | ELF read-only provider | Planned |
| 3 | PE read-only provider | Planned |
| 4 | Mach-O read-only provider | Planned |
| 5 | Archives, APK, ASAR, and plist readers | Planned |
| 6 | Inventory, search, compare, and paginated views | Planned |
| 7 | External provider protocol and engine adapters | Planned |
| 8 | JavaScript and web artifact analysis | Planned |
| 9 | Runtime analysis with authorization and isolation | Planned |

See [docs/roadmap.md](docs/roadmap.md) for phase details and non-goals.
